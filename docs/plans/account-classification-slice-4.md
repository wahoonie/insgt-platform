### Gaps pinned

**G1 — The `property_manager` tier is dropped from the backfill; the seven proxy matches become a hand-classification list.** The rule as written matches **zero** organizations (Q3e; Q9c).
```ruby
# app/models/concerns/account_query.rb — beside SQL; the users-directory shape
def order_by_sort!(options, params)
  return if params[:sort].blank?

  join_metrics!(options)
  columns = ACCOUNT_SORTS.fetch(params[:sort].to_s)
  keyword = ACCOUNT_SORT_DIRECTIONS.fetch(params[:direction].to_s)
  options[:select] = [options[:select].presence || 'accounts.*', *columns].join(', ')
  options[:group] = [options[:group], *columns].join(', ') if options[:group].present?
  fragments = columns.map { |column| "#{column} #{keyword} NULLS LAST" }
  options[:order] = Arel.sql((fragments << 'accounts.id ASC').join(', '))
end

def join_metrics!(options)
  return if options[:joins].include?(join_on[:account_metrics])

  options[:joins] << join_on[:account_metrics]   # 'LEFT JOIN account_metrics ON account_metrics.account_id = accounts.id'
end
```
