# Local Development

To start all of the services at once in the container:

    $ cd /workspace

To load all apps at once:

    $ bin/dev

To load individual apps:

    $ bin/api-app
    $ bin/api-app-ops
    $ bin/api-disclosure
    $ bin/api-galleries
    $ bin/api-ops
    $ bin/api-photographers
    $ bin/api-site
    $ bin/api-virtual-tour
