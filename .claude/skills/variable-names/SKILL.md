Do not shorten variable names. Use the full word (e.g., `description` not `desc`, `listing` not `lst`).

**Why:** Favors maintainability and readability over brevity.

**How to apply:** Always use descriptive, unabbreviated variable names in all generated code — Ruby, TypeScript, or otherwise.
